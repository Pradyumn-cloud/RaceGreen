Operator handbook

Help & commands

Configure a provider, run agents, inspect evidence, open this dashboard, and safely clean up. Copy a command, replace the values in angle brackets, and run it from the project directory. The dashboard is read-only and never executes repository commands.

First setup

Create a provider profile without storing credentials.

uv run racegreen setup

Choose Ollama for a local model or a hosted provider. Existing RACEGREEN_* environment variables override the file.

Check readiness

Check Python, Git, provider configuration, and home directory.

uv run racegreen doctor

A local provider may work without an API key. Use provider-test for a real endpoint check.

Test provider

Check that the configured endpoint responds.

uv run racegreen provider-test

This does not send a model completion.

Run one agent

Run one bounded coding agent in an isolated worktree.

uv run racegreen agent-run . "<task>"

The source repository is not modified automatically.

Run a race

Run multiple agents against the same task.

uv run racegreen race . "<task>" --agents 2 --max-concurrency 2

A winner requires configured full-suite confirmation.

Inspect runs

List recorded runs and inspect one run.

uv run racegreen runs
uv run racegreen run-show <RUN_ID>

Copy the run ID from the list, then inspect its candidates and events.

Open dashboard

Open this local operator console.

uv run racegreen dashboard --open

The server is loopback-only and the dashboard is read-only.

HTML report

Create a standalone report for one run.

uv run racegreen report <RUN_ID> --output racegreen-report.html

Open the generated file in a browser.

Events

List, export, or replay the event timeline.

uv run racegreen events list <RUN_ID>
uv run racegreen events export <RUN_ID> --output events.jsonl
uv run racegreen-replay show events.jsonl

Events are the persisted trace source of truth.

Verify database

Check SQLite integrity and event invariants.

uv run racegreen db verify

Run this after unusual interruptions or manual event ingestion.

Rebuild projections

Replay the persisted event trace into run, agent, and candidate projections.

uv run racegreen db rebuild

Useful after an older database is upgraded. Winners are preserved.

Offline demo

Try the persistence and report flow without an API.

uv run racegreen demo

The demo does not measure agent quality.

Clean artifacts

List or remove only RaceGreen-owned run folders.

uv run racegreen clean
uv run racegreen clean --run-id <RUN_ID> --yes

Review the list before removing a run.

Review and apply

Review a candidate patch before changing your repository.

git diff
git apply --check <PATCH_PATH>
git apply <PATCH_PATH>

The dashboard does not apply changes. Create a review branch first and verify the target is clean.
