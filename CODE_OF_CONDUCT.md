# Code of conduct

Be respectful, specific, and evidence-driven. Discuss code and behavior, not
people. Do not publish another person's credentials, private repository
contents, or identifying information.

Reports of harassment or security-sensitive conduct should be sent privately to
the maintainers rather than filed in a public issue. Maintainers may remove
comments, close contributions, or restrict participation when behavior is
abusive or puts users at risk.

This project follows the spirit of the Contributor Covenant, version 2.1.
